# 崩坏冷却与队友设置调整（2026-10-07，R3）

这是 R3 的历史说明。最新 R4 的 8 秒预览、已就绪名单与下一位倒计时同屏规则，见 [R4 修正记录](reminder-preview-roster-2026-10-07.md)。

适用 CN、RT、OT，OT 保留繁体界面和台服技能名称。本说明以 R3 为准；本次恢复醒目的坐标与预览入口，按截图改为竖排冷却小窗，并修复队友就绪后不切换本人冷却的问题。

## 使用方式

- 爆发提醒 → 崩坏 → 冷却提醒：「一直显示」和「提前 N 秒放大提醒」是两个独立开关，可以同时开启。
- 两项均开启时：64 × 96 竖排小窗显示完整冷却；进入提前秒数后切换为 112 × 112 方框；就绪提示 3 秒后恢复小窗或切换下一人。仅开启提前提醒则在该窗口出现，就绪 3 秒后消失；仅开启一直显示则始终使用小窗。
- 小窗从上到下显示角色昵称、技能图标、剩余秒数或状态，方框也不显示数字角色 ID。未取得昵称时本人显示「本人」，其他人显示「未知使用者」。尚未观测到释放时常驻小窗显示「未观测」，不虚构已就绪。
- 多名选中队友与本人按已知冷却结束时间选择下一位到期者。已就绪者仅保留 3 秒提示，之后让位于仍在冷却者；全部已就绪且开启常驻时，显示最近就绪者。再次释放重新参与选择，不会被其他人的旧就绪状态挡住。未选中、离开视野或已确认死亡的队友不参与候选；未知冷却不覆盖已知候选。
- 队友技能设置中单独填写的崩坏冷却优先于爆发提醒的通用秒数，服务端减冷却和重置消息仍会调整结束时间。读到下一次实际释放后重新计算并选择候选。
- 冷却小窗和吟唱／实际生效卡片可同时显示，并按各自尺寸自动错开。提前倒计时不播放声音，就绪音效每次释放最多播放一次。
- 队友姓名旁提供「模板」入口；「血量提醒」「Buff 提醒」「技能提醒」文字各自带下拉箭头、悬停和键盘焦点效果。点击文字展开设置，再次点击收起，旁边复选框独立控制是否监测。
- 管理队友区域同时只展开一名队友的一项设置；切换保留未保存修改。常用与移除操作仍放在角色名旁。
- 展开血量设置后，顶部直接显示血量 X/Y、屏幕预览与窗口示意。展开 Buff 或技能后，顶部直接显示「Buff / 技能共用悬浮窗 · 坐标与预览」，不再套第二层折叠。Buff／技能共用一套坐标，血量保留独立坐标。
- 旧配置默认提前 0 秒，延续就绪提示。首版 `cooldownMode` 自动迁移，后续保存使用两个独立布尔值，明确关闭后不会被旧模式重新打开。
- 删除旧的整行通知条，保存成功、普通信息不再弹条。失败与警告改用短暂的右下角提示，以免保存失败没有反馈。

## 本人不显示的原因

原先本人和队友共用识别检查，必须先取得完整角色入场信息才接受技能观测。但本人的身份与私人技能消息可能先到，导致真实释放被过滤。另一个问题是只收到最大血量、尚未收到当前血量时，零值被当成死亡而排除。

R2 使用已确认的本人身份接收释放消息，仍排除已知宠物／非玩家；分别记录是否收到血量与明确死亡状态，避免把未知血量判成死亡。后续入场信息补齐昵称时保留原冷却，死亡后隐藏，复活后恢复。

- 两份前端的 Vue/TypeScript 类型检查、生产构建和爆发设置持久化检查通过，覆盖旧模式迁移与两个独立开关的保存。

界面验证使用模拟队友状态，冷却行为使用后端事件回归测试；尚未做实际游戏中的多人组队验证。队友冷却仍以观测到的释放和填写的实际秒数估算。
