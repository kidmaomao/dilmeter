## 晓晓语音依赖与流程

自定义音效旁的“语音制作”支持 Edge 晓晓和 Windows 本地语音，覆盖 Buff、层数、Debuff、技能 CD、Boss、队友提醒。

| 使用方式 | 依赖 |
| --- | --- |
| 内置“绿幕即将出现”等提示音 | 无额外语音依赖，离线播放 |
| 已生成并保存的 MP3 | 无需再连接在线服务 |
| 自定义 Edge 晓晓 MP3（推荐） | 可选晓晓语音附加包，解压即可；生成时需联网 |
| 自定义 Edge 晓晓 MP3（手动依赖） | Python（建议 3.10+）、edge-tts、可连接 Microsoft 在线语音服务的网络 |
| Windows 本地语音 | Windows 已安装的系统语音，无需网络 |

不需要安装或更新 Edge 浏览器，不需要 API Key 或 FFmpeg。WebView2 是应用界面组件，与语音生成依赖不同。依据：[edge-tts 项目](https://github.com/rany2/edge-tts)、[PyPI](https://pypi.org/project/edge-tts/)（2026-10-17 核实）。

推荐方式：下载独立的晓晓语音附加包，将 addons 文件夹解压到软件 EXE 同级目录，点击“自动监测”。主程序优先检测附加包，未安装时保留已有系统 Python 的使用方式。附加包说明与复现见 [edge-tts-addon.md](edge-tts-addon.md)。

手动安装方式：

1. 安装 Python 时勾选添加到 PATH。
2. 运行 `py -3 -m pip install --upgrade edge-tts`。没有 py 命令时使用 `python -m pip install --upgrade edge-tts`。
3. 软件内点击“自动监测”，输入文字、选择语速，点击“生成、选用并试听”，然后保存提醒设定。
4. 生成时仅将输入文字发送到 Microsoft 在线语音服务。音频保存在现有自定义音效目录，以 SHA-256 命名。
5. 在线生成失败时检查网络与系统时间、更新 edge-tts，或改用 Windows 本地语音。第三方 edge-tts 接入的在线服务可用性可能变化。

内置音频使用 `edge-tts==7.3.1`、`zh-CN-XiaoxiaoNeural`、正常语速生成；复现脚本为 `scripts/generate-green-curtain-audio.py`。

## 面向中国大陆的更新方案

现有客户端已支持 GitHub 更新清单失败后切换 `https://gear.noginogi.sbs/downloads`（单个清单请求最多 8 秒）。更新包校验 HTTPS、大小和 SHA-256。当前只对清单请求失败做切换；已经选定的 ZIP 下载失败不会自动换源。

本次保留现有更新行为。已部署仅含页面和下载链接的 [Netlify 镜像](https://noginogi-downloads.netlify.app/downloads/)，不托管安装包，不作为客户端自动更新源。以下为后续更新源建议，尚未开通：

1. **优先建议：独立更新域名 + 腾讯云 COS/CDN 或阿里云 OSS/CDN。** 沿用现有三个 JSON 与 ZIP 发布格式，无需重做安装器。国内对象存储及分发节点适合提供持续可用的更新直链；具体地域、域名接入条件及费用在选型时确认。[腾讯云说明](https://cloud.tencent.com/document/product/228/38088)、[阿里云说明](https://help.aliyun.com/zh/oss/user-guide/cdn-acceleration)。
2. **低改动方案：现有下载站优先，GitHub 备用。** 需先实测大陆不同运营商的访问情况；自有域名本身不能保证下载速度。可加更新源选择和下载失败切换，切换时必须确认版本、大小、SHA-256 相同。
3. **蓝奏云继续用于手动备用下载。** 分享页不是 ZIP 直链，不适合作为自动更新清单的 URL；正式发布仍需按 `docs/releasing.md` 同步三个最终安装包及公开链接。

后续更新源实现宜使用按版本固定的 ZIP 路径，短缓存或不缓存版本清单，先上传完整包再切换清单，避免更新检查与下载跨版本。现有 SHA-256 负责完整性校验；若扩大镜像范围，建议另外加入发布清单签名和固定公钥验证。
