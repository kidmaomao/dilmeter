# 1.6.3 默认浏览器链接修正

日期：2026-10-18；本地修正版目录为 `artifacts/release-v1.6.3-r4`，应用版本仍为 1.6.3。

作者说明原先只有 `target="_blank"`，WebView2 主窗口未处理这些链接的系统浏览器打开请求。现在在主窗口首次导航前绑定 `__dilmeterOpenExternal`：链接点击立即阻止 WebView 新窗口，再通过 Windows `ShellExecute` 的 `open` 动作打开网址，由系统默认 HTTPS 应用接管，不指定 Edge 或其他浏览器。

修复范围为作者说明主站、cn 备用入口，以及晓晓语音制作中的 gear / Netlify 下载页。普通浏览器环境没有此桌面绑定，继续使用正常超链接；Windows 打开失败时页面提示复制链接手动打开。

原生入口只允许这四个内置 HTTPS 地址，拒绝本地文件、自定义协议、命令参数及其他目的地。URL 直接传给 Windows，不经 cmd 或 PowerShell。

验证包含原生调用参数、四个地址、非法链接拒绝、Windows 错误传播；前端验证点击取消默认导航、桌面回调、普通网页回退及错误提示。测试替换 OS 调用以避免自动打开用户浏览器，未据此声称完成真实浏览器窗口的端到端点击验收。发布工作流加入前端链接与主窗口绑定就绪检查。

CN、RT、OT 同步。正式发布仍需执行 releasing.md 的完整流程。
