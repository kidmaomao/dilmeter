核验日期：2026-10-04。名称按实际参与统计的技能、状态、秘法才能 ID 核对，界面语言与资源服务器独立。CN 数据与持久化键值保持不变。

## 关键区别

- 重炮 KPI 的信号使用技能 **59121 重裝武力**；不能误配到 **59122 毀滅砲擊**。
- 逆龙打断使用 **24103 連續技能 : 狂暴拳擊**；连段起手为 **24201 連續技能: 螺旋勾拳**，结束为 **24301 連續技能: 飛踢**。
- 憤怒衝擊覆盖率使用减益 **CC323**，其资源内部状态名为「傷害詛咒 2」；界面使用玩家可辨识的来源技能名。猛擊层数使用 CC321/322。
- 多尔卡资源在台服说明中写为「黑闇值」。

## 显示与验证范围

- 52 个关键 ID 已逐项与在线台服资源比对；覆盖十种职业的 30 行 KPI 标签、说明和两项爆发技能。优先使用成功载入的实时资源，未载入时使用经核对的小型名称表；未知技能只显示 ID。
- 资源切换、简繁界面独立性、损坏下载、断网缓存、旧缓存升级及切回 CN 已回归。爆发原生提示只接受与 ID 匹配的两项台服名称，名称不改变 CC、冷却或触发来源。
- 保留既有台服 0xAFFA/45050、技能 52401 射线适配，未用 CN 网络设置覆盖 OT。
- 新增 KPI 的封包口径及 0.92 秒普通连段参考值来自 CN 抓包／录像，未取得台服全职业受控实战样本。本次确认名称、数据流、单元回归与界面；不宣称所有台服实测数值已校准。缺少必要数据时保持缺少数据提示。

可复验：在 `ot/front` 执行 `npm run verify:tw-game-terms`；设置 `DILMETER_PRILUS_LIVE=1` 后执行 `npm run verify:tw-resources` 逐项核对在线资源。

1.6.0 正式界面开放九种职业 KPI；骑士枪保留计算代码和回归样例，但界面明确标为暂未开放，等待补充实战记录。
