# 1.6.3 Boss 预览及绿幕配色修正

日期：2026-10-18。本次为本地 r3 修正版，应用版本仍为 1.6.3。

## 原因与修复

“测试提醒”原先在渲染进程中创建一次模拟状态，发送给桌面覆盖层。后台实时提醒随后写入自己的状态，覆盖测试卡片，因此环绕球、射线和绿幕均会短暂出现后消失。

桌面测试现在通过 `/api/boss_mechanic_preview` 将机制类型、时长、位置和缩放提交给后端。后端使用自己的时钟记录独立预览，在每次实时刷新时合并有效预览，按截止时间清除。同一机制重复点击重新开始，不叠加多张卡片；不同机制可以同时预览。预览不修改真实战斗计时或保存设置，临时覆盖同一机制的显示后，恢复当前实战状态。

绿幕测试使用配置的提前秒数（默认 10 秒），环绕球、射线使用各自倒计时。桌面“测试提醒”不要求先启用实战规则，也不受总覆盖层开关的限制，便于调整位置。声音仍按已有音量和音效设置播放。

绿幕在原生 Windows 绘制和 WebView 两种覆盖层均使用深绿色底、明绿色边框/发光/进度条。环绕球和射线保留原有暖色与危险阶段效果。

## 验证

- CN/OT 后端回归覆盖每 200 毫秒刷新下的 20 秒环绕球、5 秒射线、10 秒及自定义 20.5 秒绿幕，截止前仍可见、截止时消失。
- 覆盖重复点击、多个预览并存、恢复真实同名机制、未启用规则时测试、非法请求及过期预览不复活。现有爆发预览和绿幕计时回归通过。
- 可选 `TestBossMechanicPreviewBrowserHarness` 提供真实接口与 200 毫秒实时刷新。浏览器使用生产的请求函数及 `SkillCooldownOverlay.vue` 验证三个卡片出现、倒数和自然消失。截图：`artifacts/v1.6.3-qa/boss-preview-green.png`。
- CN/OT 类型检查、生产构建、职业 KPI、爆裂骑士枪 KPI、战斗记录、Boss 规则回归通过；OT 台服资源和术语通过。打包另运行 RT 全量测试及嵌入资源检查。
