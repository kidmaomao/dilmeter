## 核验结果

- 最终工作流通过 CN / RT / OT 后端构建和测试、前端类型检查、职业 KPI、战斗记录、提醒及变身计时回归、OT 台服资源与术语检查。
- 三个 EXE 的文件和产品版本为 `1.6.3.0`；ZIP CRC、条目、公告、JSON 大小及 SHA-256 均通过核验。ZIP 内公告、更新清单和 GitHub 公告一致，仅平台换行符可能不同。
- 晓晓附加包包含锁定的 Python、edge-tts、依赖、许可证和源码。CI 的三版附加包集成测试通过；本地对同一 SHA-256 的最终附加包实际联网生成 12096 字节 MP3。首次本地冷启动探测超过 3 秒，直接检查运行环境后重试成功。
- 下载主站的四个 ZIP 已逐个实际下载，大小及 SHA-256 与 GitHub 一致；站内主包清单的 URL 指向 gear 下载地址。
- 四个蓝奏云分享入口的提取码和文件名通过公开下载接口验证。公开页自动点击持续超时后，由用户手动下载 CN ZIP；本地比对大小和 SHA-256 均与 GitHub 一致。
- `npm run verify:dilmeter-downloads` 通过，包括三版及附加包清单、公告、文件大小、SHA-256、蓝奏云提取码复制与 GitHub 回退。
- 主站与 Netlify 线上均显示 v1.6.3 公告、连续的 1—4 编号及四个蓝奏云入口。镜像所有 ZIP 链接均指向 gear 或 GitHub。

本地最终文件保存在 `artifacts/release-v1.6.3-final/`，核验记录与页面快照同目录保存；不发布抓包、用户配置或登录凭据。
