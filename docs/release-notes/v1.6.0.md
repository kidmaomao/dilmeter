# 【Dilmeter 1.6.0 更新公告】

## 一、全新软件界面

- 全新的 UI 设计，保留浅色与深色主题，采用渐变背景和半透明卡片，改善文字、按钮与选中状态的辨识度。
- 提醒设置改为左侧分类，共用选项和保存按钮集中管理。
- 队友提醒改为紧凑列表，血量、Buff、技能提醒可直接勾选，详细设置按需展开。

## 二、职业 KPI 战斗分析（试用）

- 新增九种职业的专属指标（作者精灵，暂缺骑士枪），支持本人及可观测的队友数据。
- 指标根据完整记录统计（测试中，对 KPI 统计指标有 bug 或意见，请联系作者）；缺少必要数据时显示提示。
- 穿心瞄准率统一在 KPI 显示：在“瞄准提醒”中填写并保存参数即可统计后续战斗，无需启用提醒即可记录。

## 三、队友技能与爆发提醒

- 圣歌提醒新增队友技能冷却监控，可以将队友大招添加为提醒。
- 新增爆发提醒，支持崩坏、万钧（团聚）的吟唱、生效倒计时及声音、位置、大小设置。

## 四、OT 台服名称适配

- 按技能、状态及秘法才能 ID 核对台服名称。
- 保留简繁界面、CN/TW 资料切换和台服既有适配。
- 新增 KPI 的统计口径来自国服记录，台服全职业实战仍待验证；相关项目保留试用说明。
