## 核验结果

- 核对了 ZIP 完整性、更新清单、程序文件属性和公告。CN、RT、OT 的程序及产品版本均为 `1.6.7.0`，实际启动后均可预览新版队友浮窗。
- 从 Gitee 免登录下载了三个 ZIP，并核实三份公开更新清单中的版本、公告、下载地址、大小和 SHA-256。[CN 清单](https://gitee.com/kidmao100/dilmeter-releases/raw/master/latest/DilmeterCN.json?version=1.6.7) · [RT 清单](https://gitee.com/kidmao100/dilmeter-releases/raw/master/latest/DilmeterRT.json?version=1.6.7) · [OT 清单](https://gitee.com/kidmao100/dilmeter-releases/raw/master/latest/DilmeterOT.json?version=1.6.7)
- 核实四个蓝奏云文件的公开名称、大小和提取码。通过公开分享下载的 CN ZIP 与 GitHub 的 SHA-256 一致。
- 主页和备用页均展示完整的三条确认稿、三个 Gitee 入口、四个蓝奏云文件入口及版本目录提取码。下载页自动发现三端新版时会一并更新公告。
- 下载页通过 `npm run verify:dilmeter-downloads`。主站四个下载的大小和 SHA-256 与正式文件一致，站内清单指向本站 ZIP。Netlify 公告与主站一致，四个旧下载路径均以 302 跳转到主站。
- 晓晓语音附加包版本为 `1.0.0`。正式工作流通过了三个版本的附加包集成检查。

## 已确认的更新公告

```text
Dilmeter v1.6.7

1、队友浮窗更紧凑
收窄队友浮窗，略微加高血条和魔法条。技能与 BUFF 图标放大，仍在每位队友的状态条下方横排，倒计时显示在图标底部。图标排满后自动换行，窗口宽度保持固定。

2、队友浮窗跟随 DPI 缩放
队友浮窗沿用 BUFF 浮窗的 DPI 设置，支持跟随显示器自动缩放，也可使用手动设置的比例。

3、BUFF 提醒支持手动排序
可用上下箭头调整 BUFF 的显示顺序，保存后生效。时长、闪烁和音效选项横向排列，窗口较窄时自动换行。
```
