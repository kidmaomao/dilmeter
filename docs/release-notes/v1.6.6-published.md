## 核验结果

- 三个正式 ZIP 的完整性、文件及公告均已核验。EXE 文件版本和产品版本均为 `1.6.6.0`，CN、RT、OT 分别通过隔离启动检查。「治愈之手」监测接口在三个版本中均可用。
- 发布工作流从 Gitee 免登录下载三个正式 ZIP 并核对 SHA-256，同时读取了三份公开更新清单，版本、大小、SHA-256、公告及 Gitee ZIP 地址均匹配。[CN 清单](https://gitee.com/kidmao100/dilmeter-releases/raw/master/latest/DilmeterCN.json?version=1.6.6) · [RT 清单](https://gitee.com/kidmao100/dilmeter-releases/raw/master/latest/DilmeterRT.json?version=1.6.6) · [OT 清单](https://gitee.com/kidmao100/dilmeter-releases/raw/master/latest/DilmeterOT.json?version=1.6.6)
- 蓝奏云四个公开分享入口的提取码、文件名称和显示大小均已核对。通过公开分享页下载的 CN 包与 GitHub 的字节数和 SHA-256 一致。
- 下载站校验 `npm run verify:dilmeter-downloads` 已通过。主站四个 ZIP 均已免登录下载并通过字节数与 SHA-256 校验，三个站内更新清单指向对应 ZIP，版本、公告及校验值均匹配。
- Netlify 公开页返回 HTTP 200。两页显示同一份公告、三个 Gitee 入口和四个本次蓝奏云入口。Netlify 发布目录含九个页面资源或路由文件，四个旧 ZIP 路径均以 HTTP 302 跳转到已验证的主站文件。
- 晓晓语音附加包版本为 1.0.0，校验值与上版一致。CN、RT、OT 全部通过集成检查，使用附加包运行环境联网生成了 11808 字节的 MP3。

本地最终产物及核验记录保存在 `artifacts/release-v1.6.6-final/`。

## 发布公告

```text
Dilmeter v1.6.6

1、队友浮窗合并
进入副本后自动识别队员
重做组队浮窗，角色名后显示技能小图标和剩余冷却，并显示帷幕情况
临时队友可编辑监测内容或添加为常用，常用队友列表可折叠。识别阿尔卡纳职业后，自动添加对应的演奏与技能冷却预设，可自行调整。

2、新增佩隆机制提醒
支持幻影血条、共鸣切换计时和尔格龙卷风预警，龙卷风可分别监测自己和队友。

3、抓包与提醒修复
改进游戏连接识别，减少切频道时抓包误停。每次重新开启抓包会保存为独立文件。

4、修复「治愈之手」
多次对同一目标施放时，后续冷却可能未触发的问题。不同提醒的预览可以同时显示，并各自结束。
```
