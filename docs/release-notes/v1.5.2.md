# Dilmeter v1.5.2 更新公告

适用版本：DilmeterCN、DilmeterRT、DilmeterOT。

1. 团队 DPS 曲线修改


   默认显示「最近 5 秒 DPS」，方便查看大招、连击和停手带来的变化，统计窗口支持切换为 1、2、5、10 秒。

   同时保留「累计 DPS」，按累计伤害 ÷ 已经过的战斗时间计算，可回顾战斗各时刻的平均输出。

   已记录的 Boss 无敌、成员倒地区间以虚线标注。没有新增伤害时，近期 DPS 随伤害移出窗口降至零，累计 DPS 则随时间继续下降。

2. 新增 DPS 峰值标记与技能分析


   在近期 DPS 曲线上标记主要峰值，点击即可查看该窗口内主要技能的伤害、占比、伤害次数，以及相较前一窗口的伤害变化，支持分析单个成员或全团。

   同时展示记录到的 时间扭曲、连击相关状态，以及队友的崩坏波动、万钧之力等施放或状态信息，并注明自己、队友或召唤物的来源（测试阶段）。

3. 团队绘图支持 Boss 血量横坐标


   累计伤害、DPS 曲线和技能时间轴均可切换 「战斗时间／Boss 血量 %」，方便对照不同血量阶段的输出和技能使用情况。

4. 新增黑魔导士「烬火引燃」能量与 CD 联合提醒


   技能 ID：59047。开启「魔法穿刺」（59046）后监测能量，同时显示技能 CD；能量达到设定进度且 CD 完成时触发提醒。

   首次观测到成功施放后开始 CD 计时，此前显示「CD 待观测」。CD 默认 30 秒，可按游戏内实际值调整。

5. 新增圣盾骑士「牺牲之惩戒」能量提醒


   技能 ID：59085。开启「高贵的誓约」（59088）后监测能量，达到设定进度时触发提醒。

   两项新提醒均可在 「提醒设置 → 技能冷却完成提醒」 中按名称或技能 ID 添加，默认能量提示进度为 100%，支持常驻显示、自定义提示进度及音效。

6. 修复 Buff 提醒设置无法保存


   修复图标大小等设置在保存时被旧值覆盖、修改不生效的问题。覆盖层保持锁定时，也可正常修改并保存图标尺寸。

说明：无敌、倒地和峰值状态分析依赖实际记录到的数据；旧记录中缺失的信息无法补算。
