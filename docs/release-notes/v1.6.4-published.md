## 核验结果

- CN / RT / OT 后端测试、前端类型检查、职业 KPI、战斗记录、实体化、魔法值、机制覆盖层及狂乱统计回归通过；OT 台服资源和术语检查通过。旧 OT 热修复显示版本兼容逻辑保留。
- CN 和 OT 的实际界面验证覆盖检查失败后恢复、选择 Gitee、重载后记住来源、安装请求携带来源及下载失败后重试。
- 自动换源回归覆盖请求失败、连接和响应体停滞、损坏包、旧版镜像、不同大小或 SHA-256、取消请求及临时文件清理。
- 最终 EXE 文件及产品版本均为 `1.6.4.0`。三个 ZIP 内公告与用户确认稿一致，清单和包的大小、SHA-256 一致；最终 EXE 不包含 `/api/skill_bar`、`handleSkillBar`、`SkillBarSettingsDialog`。
- Gitee 三个 ZIP 均通过本机及 GitHub 云端免登录完整下载校验；`raw/master/latest/DilmeterCN.json`、`DilmeterRT.json`、`DilmeterOT.json` 公开访问正常，URL 指向对应 Gitee ZIP。
- 蓝奏云四个文件的公开接口均验证名称和提取码；浏览器自动点击超时后，用户手动下载 CN 包，大小及 SHA-256 与 GitHub 完全一致。
- 下载主站四个 ZIP 已逐个实际下载，大小及 SHA-256 全部匹配；清单 URL 均指向站内 ZIP。页面包含七项原文公告、三版 Gitee 入口及四个本次蓝奏云入口。
- Netlify 仅发布 9 个静态页面、样式、脚本、图标及路由文件；线上 200，公告、Gitee 和蓝奏云入口均已同步。所有 ZIP 链接指向 gear / GitHub / Gitee，没有通过 Netlify 托管或代理安装包。
- `npm run verify:dilmeter-downloads` 通过，包括来源、版本、公告、哈希、提取码复制和隐藏不同版本镜像入口。
- 晓晓附加包与上版相同，使用最终解压目录通过集成检查；本机实际联网生成 12096 字节 MP3。

本地最终产物及核验 JSON 保存在 `artifacts/release-v1.6.4-final/`。发布仓库和安装包不含抓包、用户配置或凭据。
