# Dilmeter v1.5.0 更新公告

- 新增「圣歌监测」：可为每位队友独立设置低血量提醒，监测战争序曲、活跃进行曲及自选 Buff。
- 支持保存常用队友与通用模板，可预设「队友1／队友2／队友3」后直接套用。勾选或取消常用状态立即保存；其他改动未保存时，保存按钮会闪烁提示。移除队友增加确认步骤。
- 提醒音效，可分别设置音量、提醒次数与间隔。悬浮提示显示队友名称，支持调整位置、字号、图标大小、透明度及屏幕预览。
- 修复 Boss 战结束时，最后几次伤害被错误切成一场新战斗的问题，保留历史场次按需加载。
- 多尔卡精通提醒新增窗口大小设置，支持 50%～200% 缩放。
- 精简发布包，程序 EXE 缩减至约 30 MB，保留原有功能和内置资源。
