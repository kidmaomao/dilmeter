# 连续躲避演示：来源与边界

参考视频：[【自制】少人局牢马50%](https://www.bilibili.com/video/BV1bH9sBXEW9/)。
原模拟器：[Canvas ver1.1](https://chatgpt.com/canvas/shared/69d47b6663f88191af8f8d8d5a517be1)。
本次通过公开页面读取了源码，纠正了此前只凭画面估计的判定时长和移动速度。

## 已核实的原模拟器规则

| 项目 | Canvas 源码行为 |
| --- | --- |
| 固定射线 | 出现瞬间读取人物坐标，随机选横/纵，再锁定人物所在行/列；之后不跟随人物 |
| 网格 | 横纵各三条相接宽带；中间带宽为圆直径的一半；外围带延伸到圆外 |
| 颜色 | 红色 500 ms、青色 500 ms 都是判定前的提示；1000 ms 时检查一次人物是否在线内，黄色保留 90 ms |
| 出线频率 | 依次 1260、1080、945、810、756 ms，之后保持 756 ms；判定延迟仍为 1000 ms |
| 移动 | 普通速度为每秒 2.5 个圆直径，即 5 个半径；人物半径为圆半径的 28.8 / 330 |
| 额外线 | 模拟器有独立随机落点，不能用人物位置来替代；同类同格重复有排除规则 |
| 通关 | 圈内累计 15 秒后进入庆祝阶段；该模拟器的庆祝阶段不再执行死亡检查 |

这些是第三方练习模拟器的规则，**不是已经核实的游戏规则**。用户提供的实战识别初始 1.6 秒与 Canvas 的 1 秒必须分别使用。死亡触发额外线、对侧玩家影响以及游戏内具体判定时长仍需实测。

## 本段 20 秒演示

前 2 秒为入场展示，随后展示完整 15 秒倒计时及尾部射线结束。本段使用视频采样的固定线方向和出线时刻（与源码间隔接近，受 30 fps 帧粒度影响），**没有使用视频人物的旧行列来决定新演示的射线位置**。

每次触发固定线时都读取这次演示的人物位置；新线只在出现后提供给规划器。独立额外线取视频可确认的两次可见带：约 03:40.933 下行与 03:47.000 上行，落点不由演示人物决定。画面无法证明它们在实战中的来源，因此本段不把它们称为死亡线或对侧线。此为按参考规则重建的一段完整躲避样例，不是逐帧复刻视频所有鼠标输入与随机事件。

- 原生规划器提供候选落点；演示控制器选择受保护的起步时刻，并实际跟随所显示的箭头。
- 每次新观察都重新校验路线；已在移动中的角色不会因为新预警尚未致命而突然停在旧线里。
- 原模拟器是单次命中检查。为了复用区间接口，本段使用 1 ms 的保守区间，同时保留规划器的 150 ms 时间余量、人物体积及空间余量。
- 每 10 ms 及每一个准确出线时刻推进状态；独立检查两帧之间的扫掠路径。发生命中或出圈即令导出失败，不能命中后继续导出。
- 即使倒计时归零，本段仍检查尾部射线直到全部结束；没有借用 Canvas 的庆祝无敌来伪造安全路径。
- 通过样例共 19 条固定线、2 条独立额外线、18 次移动，17.890 秒时全部判定及余量结束。此结论只适用于本段输入，不代表任意随机组合都可解。
- 图中虚线圆表示固定线锁定时的人物位置；实体圆是当前人物；“准备/现在移动”是演示控制器的时机提示。

这次按 Canvas 正视图绘制：对称九宫格、每条宽带占直径一半。此前按用户参考图设定的偏移矿石布局仍保留在原生预览中；两种布局都没有线间缝隙，实战覆盖层应使用校准结果。

## 原有错误已移除

旧版把出线行列写死、把原模拟器单次判定改成持续危险 450 ms，并把速度慢算了一倍；还允许命中后继续演示。这些不能作为正确走位的依据。旧视频帧采样中的行列保留为 sourceVideoLanes，仅用于核对来源，禁止驱动新演示的固定线。

演示的起步策略仍在导出测试脚本中，**尚未作为已校准的实战时机功能接入覆盖层**。覆盖层依旧消费真实识别器提供的射线几何与绝对判定时间，不使用此演示配置，也不操控角色。

## 重建

在仓库根目录执行：

~~~powershell
$env:DILMETER_BRONTAS_CADENCE_OUT = "$PWD\docs\demos\brontas-guide\frames-cadence.json"
Push-Location cn-rt
go test ./cmd/dilmeterapi -run '^TestExportBrontasCadenceDemo$' -count=1
Pop-Location
Remove-Item Env:DILMETER_BRONTAS_CADENCE_OUT
Push-Location docs/demos/brontas-guide
npm install
node render.mjs frames-cadence.json brontas-guide-demo.gif
Pop-Location
~~~

渲染器会拒绝不属于三行三列的射线；中文文字预先转换为轮廓并缓存，避免每帧重新加载字体。测试无需生成 GIF 即可运行：
~~~powershell
go test ./cmd/dilmeterapi -run 'TestBrontasGrid|TestBrontasDemoPositionLockedContinuous|TestBrontasDemoDetectsContact' -count=1
~~~
