# 变身技能识别修复（1.6.3-r5）

## 原因与抓包证据

2026-10-18 用户提供的抓包经原有 TCP 重组和消息解析，共得到 252 个游戏包，解析错误为 0。狂暴精灵（43001）使用后，服务器先发送 27044 启用变身附带技能，再在时间戳 1792254730604 发送 27020，内容为 short(43001) 和空字符串。该次变身没有普通技能使用所走的 27016 通知，也没有对应的伤害动作。

旧版仅处理普通执行及战斗动作，因此日志和持续时间提醒都漏掉了这次使用；截图中的技能 ID 43001 与“自身”设置正确。

原始 PCAP 与 NDJSON 只用于本地分析，不纳入源码或发布包。

## 修改

- CN/RT 与 OT 同步处理 27020 的成功完成通知，只接受本地角色、明确的消息结构和种族变身激活技能 40001、41001、42001、43001、44001。
- 走已有技能使用事件流程，使持续时间提醒、冷却记录得到相同的成功使用信号；保留用户配置时长。
- 忽略准备、取消、附带被动技能启用、普通技能完成及其他角色；重复的同一完成时间不重启提醒。
- 不根据角色外观或登录时的技能列表猜测施放，避免已变身角色出现时误触发。

## 验证

- 合成回归覆盖五种变身 ID：事件归属、1800 秒持续时间与冷却、相同包去重、之后再次变身及异常/非施放信号。
- 本地可选实测：设置 DILMETER_TRANSFORMATION_PCAP 后运行 TestTransformationCaptureReplay。252 包只触发一次狂暴精灵事件，开始时间为 1792254730604；验证后台刷新、到期前及到期时的原生悬浮层输出。
- 该实测抓包只包含狂暴精灵，其他变身按同类协议兼容并通过合成测试，未宣称已逐个游戏实测。
- CN/RT/OT 后端全量测试、两套前端类型检查、职业 KPI、战斗记录、持续时间和冷却回归通过；OT 台服资源与术语检查通过。旧的冷却回归脚本直接通过 Node 执行时无法解析无扩展名 TypeScript 导入，本次改用项目已有的 Vite 加载器执行同一脚本并通过，未修改产品前端。
- 本地包目录为 artifacts/release-v1.6.3-r5，软件版本仍为 1.6.3；正式发布需继续遵循 releasing.md。
