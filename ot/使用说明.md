# DilmeterOT 使用说明

DilmeterOT 是独立的自定义服务器版本，允许用户自行填写游戏服务器的 IPv4 地址或 CIDR 网段以及端口。

当前版本：**v1.4.2**。

## v1.4.2 主要更新

- 更新内置国服技能、Character Condition（状态）名称和配套图标；资料随程序提供，可离线读取。
- “米耶尔 60% 安乐碎片”扩展为“安乐碎片机制”：普通米耶尔 80%、60%、40% 与米耶尔：悔恨 80% 可分别勾选，共用血条大小、透明度和位置。
- 新增“伤害增益效果计时条”，可按技能或状态配置触发来源、作用对象、持续时间、常驻显示、方向、大小、透明度与坐标。
- 计时条保留图标；纵向省略名称，去除外层背景框，加粗进度条并居中显示剩余时间，临近结束时渐变为红色。
- 修正不协和音（状态 1176）、音波洗礼（技能 59009）等名称或图标显示异常，以及部分 Windows 目录路径导致历史日志清理失败的问题。
- 保留自定义 IPv4/CIDR 网段、多端口和加速器兼容设置，不包含 WinDivert。

## OT 外服资料替换

默认内置国服资料，可直接离线读取。使用其他服务器资料时，从 Prilus 下载相应的数据和版本文件，放入 `data/resource-pack`，设置 `active-region.txt` 后重启；具体目录示例见同包的 [外置资源包说明](./RESOURCE_PACK.md)。当前入口替换资料数据及版本信息，不提供全部外服图标的一键切换。恢复默认资料时，关闭软件并移走整个资源包目录后重启。

## 一、需要的软件环境

- 操作系统：Windows 10 或 Windows 11，64 位版本。
- Npcap：必须安装，用于读取本机的游戏网络数据。安装时建议勾选 **Install Npcap in WinPcap API-compatible Mode**（WinPcap API 兼容模式）。
- Microsoft Edge WebView2 Runtime：用于显示软件界面。Windows 10/11 通常已经自带。

若提示“无法打开抓包设备”，请确认 Npcap 已正确安装，再尝试右键以管理员身份运行 DilmeterOT。

## 二、设置服务器

1. 双击 `DilmeterOT-v1.4.2.exe`。软件可以在游戏启动前独立打开，不会显示 CMD 窗口。
2. 点击窗口右上角的服务器设置按钮。
3. 在“服务器 IP / CIDR 网段”中填写以下任一格式：
   - 单个 IPv4，例如 `203.0.113.25`，保存后会自动规范为 `203.0.113.25/32`。
   - CIDR 网段，例如 `211.147.76.0/24`。
4. 在“服务器端口”中填写一个或多个端口，例如 `11020, 11021, 11023`。多个端口可用逗号、分号或空格分隔。
5. 点击“应用设置”。设置会立即保存并在运行中生效。
6. 启动游戏并登录角色。**打开软件或修改服务器设置后，需要在游戏内切换一次地图，软件才会开始捕捉。**

使用 UU 等加速器时，请勾选 **加速器兼容**。程序会检测直连、本地代理、虚拟网卡连接以及由加速器进程持有的目标服务器连接。勾选后请在游戏内切换一次地图。

仅填写自己有权连接和监测的服务器地址。DilmeterOT 只接受 IPv4；端口必须是 1 到 65535 之间的数字，并且至少填写一个。

## 三、软件功能

### 状态与服务器

- 顶部状态会显示“等待游戏”“正在连接游戏”“正在监测”“记录回放”或错误提示。
- 服务器设置可在运行中修改；应用后当前捕捉会停止并重新等待新的服务器连接，不需要重启软件。
- 加速器兼容模式只有在成功解析出洛奇封包后才会锁定连接，不会仅凭加速器进程存在就开始统计。

### 战斗目标与分享角色

- **战斗目标**：选择要查看的首领或战斗对象；名称后会显示该场战斗的起止时间，便于区分同一目标的先后场次。
- **分享角色**：选择要查看和生成图片的玩家。角色名称后会显示该角色伤害及对当前首领的贡献占比。
- **记录 DPS**：关闭后仍保留 Buff、Debuff、技能 CD 与 Boss 机制提醒，但不再生成新的伤害统计，也不会把新的伤害事件写入自动 NDJSON 日志；再次开启后从新的战斗数据开始记录。

### 顶部功能按钮

- **刷新信息**：从软件当前日志重新载入实时战斗数据。查看导入记录后，也可用它返回本次运行的实时数据。
- **导入记录**：导入软件生成的 `.json` 战斗记录，也兼容原始 `.ndjson`、`.txt`，用于重新查看历史数据。
- **导出日志**：把当前选择的首领场次保存为 UTF-8 `.json` 文件，之后可以再次导入。
- **复制图片**：按游戏“详细战斗统计”界面生成分享图并复制到剪贴板。若系统不允许直接写入剪贴板，会自动改为保存 PNG。
- **清空数据**：清除当前页面已经统计的数据，不会删除磁盘中已经保存或自动生成的日志文件。
- **数据位置**：配置、自动日志、自定义音效与界面数据统一保存在 EXE 所在文件夹的 `data` 目录；原始 NDJSON 日志位于 `data\logs`。首次启动新版时会复制旧 `%AppData%\DilmeterOT` 中尚未迁移的数据，旧文件不会删除。

### 报告标签页

- **综合**：显示技能伤害、首领贡献、最大单次伤害、攻击次数、暴击次数、主动/被动伤害比例及推测职业；下方按整场战斗统计玩家 Buff 或怪物 Debuff 的覆盖率，点击状态图标可查看生效时间轴。时间轴会按战斗时长与窗口宽度自动增加主、次刻度。
- **玩家 Buff 管理**：点击左侧“管理 Buff”可启用或删除默认状态；搜索框支持状态名称模糊搜索和 CC ID 精确搜索。玩家 Buff 按类别折叠，点击卡片右上角星标可收藏并固定显示。
- **推测职业**：覆盖元素骑士、圣光颂唱者、黑魔导士、流星射手、圣盾骑士、爆裂骑士枪、枪炮师、禁术炼金师、旋律操纵师和狂怒斗士。
- **攻击技能**：按累计伤害排序显示技能图标、伤害、DPS、占比、最大伤害、使用次数和暴击次数。第一名绿色条为满格，其他技能按相对伤害缩放。
- **人偶伤害**：人偶作为攻击主体时，伤害会自动计入操纵该人偶的玩家；宠物伤害不会计入。
- **提醒设置**：集中管理桌面 Buff 图标、持续时间来源、闪烁倒计时、音效倒计时，以及技能 CD 完成提示。可同时监控多个 Buff 和多个技能。

### 桌面 Buff 提醒

- 在“提醒设置”标签页中按名称或 CC ID 添加一个或多个 Buff，并分别启用桌面图标、闪烁与音效。
- “覆盖层开启”按钮可临时隐藏或恢复 Buff 与技能 CD 两个覆盖层；暂停时不会删除配置，也不会停止后台计时和统计。软件下次启动时会自动恢复显示。
- “透明度”滑杆可在 20%～100% 之间同时调整 Buff 图标、技能图标、粒子和倒计时的透明度。
- “DPI”默认选择“自动”，会按照悬浮窗当前所在显示器及 WebView 的实际缩放校正窗口，避免图标被切成竖条。若个别电脑自动识别不正确，可手动选择与 Windows“显示缩放”一致的 100%～300%，保存后立即生效。
- 启用“显示图标”后，该 Buff 会常驻悬浮栏：尚未监测到时为黑白暗色，实际生效后恢复彩色并显示倒计时。
- 桌面提醒只读取私有状态包指出的本机精确目标 ID；队友或宠物把 Buff 加到本机角色上仍会提醒，已确认是宠物的目标、其他玩家和其他玩家的宠物不会触发。
- “提醒设置”页右上角直接提供图标大小、提醒音量及固定的 X、Y 屏幕坐标。坐标输入后会立即移动。
- 图标大小按正方形计算，例如 30 px 即 30×30；倒计时以白字黑边显示在图标正下方。覆盖层在洛奇或 DilmeterOT 位于前台时显示；锁定时穿透鼠标，解锁后可拖动调整位置。
- 新增、删除或修改提醒后，点击该页右上角“保存设定”统一保存。已添加的 Buff、技能、图标大小、音量、Buff 悬浮坐标及每个技能各自的提示坐标会一并保留。
- “自动读取”只使用状态数据中的有效失效时间；若游戏数据未提供时长，会以绿色小字提示“不能识别持续时间”，不会猜测或套用备用值。也可改用“手动固定时长”。重复获得或提前续上同一 Buff 时，会以最新获得时间重新计时。
- 闪烁提前秒数与音效提前秒数相互独立；选择音效或点击“试听”会立即播放一次。
- 每个 Buff 可选择内置音效，也可上传一个不超过 10 MB 的 MP3/WAV 作为自己的自定义提示音；软件会复制保存，原文件之后移动或删除也不影响播放。

### 安乐碎片机制血条

- 在“提醒设置 → Boss 特殊机制提醒 → 安乐碎片机制”中，分别勾选普通米耶尔 80%、60%、40% 或米耶尔：悔恨 80% 阶段，然后点击“保存设定”。
- 对应机制开始后，选中符合条件的安乐碎片会显示放大血条；切换碎片时跟随目标，目标死亡、消失或改选其他目标时隐藏。
- 四个阶段共用 X/Y 坐标、50%～200% 大小及 20%～100% 透明度，无需重复调整。
- 点击“预览血条”可显示 5 秒预览；解锁覆盖层后可拖动血条调整位置。
- 原有 60% 阶段的开关、大小和位置会迁移到新设置；新增阶段默认关闭，需自行勾选。环绕球和射线提醒仍分别设置。

### 伤害增益效果计时条

1. 打开“提醒设置 → 伤害增益效果计时条”，点击“添加计时条”。
2. 选择“技能”或“Character Condition”作为触发来源，通过名称候选项或 ID 指定技能／状态，并选择作用对象“自身”或“怪物”。
3. 填写持续时间（秒）；勾选“到期后一直显示空条”可常驻保留图标和空条，不勾选则到期隐藏。
4. 选择横向或纵向，并设置大小（50%～200%）、透明度（20%～100%）和 X/Y 坐标。可预览，解锁覆盖层后可拖动调整位置。
5. 点击本区域的“保存设定”。检测到匹配技能执行或状态出现后开始倒数，重复触发会重新计时；匹配状态提前消失时结束该计时。

横向显示图标和名称，纵向保留图标并省略名称。剩余时间显示在进度条中央；条随时间缩短，颜色逐渐从青绿经黄橙转为红色。计时以用户填写的持续时间为准，不自动推算游戏实际增伤数值。

### 技能 CD 完成提示

- 可按技能名称或技能 ID 搜索并添加多个技能，为每个技能填写当前装备与状态下的实际 CD 秒数。
- 技能图标大小可在 24～96 px 间独立调整，不受 Buff 图标大小影响。
- 软件会捕捉服务器确认的玩家本体技能释放并开始倒计时。完成时会在该技能独立坐标显示放大、弹动、光粒子动画并播放短提示音。
- 勾选“技能图标一直显示”后，冷却期间会以灰色图标和倒计时常驻显示；CD 完成后恢复为彩色常驻图标。
- 协议中尚未找到权威的剩余 CD 或条件刷新事件，因此特殊条件造成的提前刷新、动态减 CD、充能或共享 CD 暂不能保证准确。
