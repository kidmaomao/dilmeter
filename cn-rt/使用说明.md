# DilmeterCN 使用说明

DilmeterCN 是《洛奇》CN 服务器使用的伤害监测工具。

当前版本：**v1.5.0**。

## v1.5.0 主要更新

- 新增「圣歌监测」：可为每位队友独立设置低血量提醒，监测战争序曲、活跃进行曲及自选 Buff。
- 支持保存常用队友与通用模板，可预设「队友1／队友2／队友3」后直接套用。勾选或取消常用状态立即保存；其他改动未保存时，保存按钮会闪烁提示。移除队友增加确认步骤。
- 提醒音效，可分别设置音量、提醒次数与间隔。悬浮提示显示队友名称，支持调整位置、字号、图标大小、透明度及屏幕预览。
- 修复 Boss 战结束时，最后几次伤害被错误切成一场新战斗的问题，保留历史场次按需加载。
- 多尔卡精通提醒新增窗口大小设置，支持 50%～200% 缩放。
- 精简发布包，程序 EXE 缩减至约 30 MB，保留原有功能和内置资源。

## v1.4.3 主要更新

- 优化长时间运行后的加载体验：长时间最小化、放置后台后，实时监测仅加载最新场次，历史场次在点击选择后读取，减少累积数据带来的卡顿。
- 新增多尔卡能量提醒：在“多尔卡精通”的“CD 提醒”中启用，默认少于 3 点时弹框显示当前数量，直至满足设置值后消失。支持自定义阈值、常驻显示，以及关闭或自定义提示音。
- 修复米耶尔“神剑（射线）”提醒失效的问题。
- 团队绘图新增实时 DPS 曲线，可按 1、2、5、10 秒查看全团与各成员输出变化，并显示全团峰值及对应时间段。

## v1.4.2 主要更新

- 更新内置国服技能、Character Condition（状态）名称和配套图标；资料随程序提供，可离线读取。
- “米耶尔 60% 安乐碎片”扩展为“安乐碎片机制”：普通米耶尔 80%、60%、40% 与米耶尔：悔恨 80% 可分别勾选，共用血条大小、透明度和位置。
- 新增“伤害增益效果计时条”，可按技能或状态配置触发来源、作用对象、持续时间、常驻显示、方向、大小、透明度与坐标。
- 计时条保留图标；纵向省略名称，去除外层背景框，加粗进度条并居中显示剩余时间，临近结束时渐变为红色。
- 修正不协和音（状态 1176）、音波洗礼（技能 59009）等名称或图标显示异常，以及部分 Windows 目录路径导致历史日志清理失败的问题。

## 一、需要的软件环境

- 操作系统：Windows 10 或 Windows 11，64 位版本。
- Npcap：必须安装，用于读取本机的游戏网络数据。安装时建议勾选 **Install Npcap in WinPcap API-compatible Mode**（WinPcap API 兼容模式）。
- Microsoft Edge WebView2 Runtime：用于显示软件界面。Windows 10/11 通常已经自带；若启动时提示缺少 WebView2，请安装微软官方运行库。

如果软件提示“无法打开抓包设备”，请先确认 Npcap 已正确安装，再尝试右键以管理员身份运行 DilmeterCN。

## 二、首次启动与服务器选择

1. 双击压缩包中的 `DilmeterCN-*.exe`。
2. 在软件右上角的“服务器”中选择角色所在服务器：伊鲁夏或亚特。
3. 选择会自动保存，下次打开软件时会继续使用上次选择的服务器。
4. 启动游戏并登录角色。
5. **打开软件或切换服务器后，需要在游戏内切换一次地图，软件才会开始捕捉。** 可以通过进入另一场景、房间或频道触发新的连接数据。
6. 软件状态变成“正在监测”后，进入战斗即可查看伤害。

如果一直显示“等待游戏”，请检查所选服务器是否与角色实际所在服务器一致，并再次切换一次地图。

## 三、软件功能

### 状态与服务器

- 顶部状态会显示“等待游戏”“正在连接游戏”“正在监测”“记录回放”或错误提示。
- “服务器”可在伊鲁夏与亚特之间切换。运行中切换时，当前捕捉会停止并重新等待所选服务器，不需要重启软件。
- 使用加速器时，可勾选 **加速器兼容**。勾选后请在游戏内切换一次地图。
- 加速器兼容模式只有在成功解析出洛奇封包后才会锁定连接，不会仅凭加速器进程存在就开始统计。
- UU 加速器“路由模式”无法使用 CN 版时，请改用 DilmeterRT。

### 战斗目标与分享角色

- **战斗目标**：选择要查看的首领或战斗对象；名称后会显示该场战斗的起止时间，便于区分同一目标的先后场次。
- **分享角色**：选择要查看和生成图片的玩家。角色名称后会显示该角色伤害及对当前首领的贡献占比。
- **显示 DPS**：关闭后只隐藏伤害统计界面；网络捕捉、自动 NDJSON 日志、Buff、Debuff、技能 CD 与 Boss 机制提醒仍照常运行，切换地图也不会中断状态识别。

### 顶部功能按钮

- **技能栏**：打开独立技能栏配置。先选择格子，再搜索技能、录制按键序列和实际 CD；一组同时按下的键是一段，松开后可继续录下一段，例如 `Ctrl+[ → Q`。每格最多 8 段、每段最多 4 个键。保存后显示原生悬浮技能栏。需要移动时先解除锁定并保存，再拖动悬浮栏，最后重新锁定。
- **刷新信息**：从软件当前日志重新载入实时战斗数据。查看历史记录后，也可用它返回本次运行的实时数据。
- **查看记录**：弹窗列出 `data\logs` 中的原始战斗记录，首次只加载 10 条，向下滚动时再继续加载。收藏记录固定置顶，其余按日期和开始时间降序排列。列表先按“雷内恩的米耶尔：悔恨 → 雷内恩的米耶尔 → 布隆塔纳斯 → 枯木之佩塔克”的顺序选择该日志的 DPS 统计目标；四类目标都不存在时，才选择其他最大血量（无血量数据时按累计承伤估算）达到 1 亿的 Boss 级目标。同一种 Boss 在日志中出现多场时，每位玩家显示其中自己的最高 DPS，列表同时标明采用的 Boss 名称。这样不会再被短时间存活的小怪抬高。列表仍保留伤害条数、技能数、攻击者/目标数量和文件大小。“删除”会经过二次确认，并永久删除该次运行对应的 NDJSON、TXT 和 PCAPNG 文件；本次运行的记录不允许删除，删除完成后列表会保留当前加载页数和滚动位置。点击“查看”后可选择任意战斗目标与有伤害的队员；从详情顶部或底部返回记录列表时，会回到查看前的原滚动位置。若日志已记录 Boss 最大生命值，目标选项会显示真实血量，否则明确标为“血量未知”。首屏显示 DPS、副本时间，以及全部队员的“DPS / 累计伤害（占目标血量或累计承伤比例）”；展开“技能占比”后，可在占比旁直接查看累计伤害，并查看最大单次伤害、使用次数以及暴击次数（比例）。弹窗右上角的“打开其他文件”仍兼容 `.json`、`.ndjson`、`.dilmetercn` 和 `.txt`。
- **导出日志**：把当前选择的首领场次保存为 UTF-8 `.json` 文件，之后可以再次导入。
- **复制图片**：按游戏“详细战斗统计”界面生成分享图并复制到剪贴板，可直接粘贴到聊天软件。若系统不允许直接写入剪贴板，会自动改为保存 PNG。
- **清空数据**：清除当前页面已经统计的数据，不会删除磁盘中已经保存或自动生成的日志文件。
- **数据位置**：配置、自动日志、自定义音效与界面数据统一保存在 EXE 所在文件夹的 `data` 目录；原始 NDJSON 日志位于 `data\logs`。首次启动新版时会复制旧 `%AppData%\MabinogiDpsDesktop` 中尚未迁移的数据，旧文件不会删除。
- **历史日志清理**：当 `data\logs` 中的日志总大小超过 10 GB，或存在两个月以前的日志时，软件会询问是否清理。你可以选择截止日期并先查看文件数量与大小；确认后，只有该日期 00:00 之前的历史日志会移入 Windows 回收站，所选日期当天、本次运行正在写入的日志、子目录和其他文件都会保留。清理后请手动清空回收站以释放磁盘空间。

### 报告标签页

- **综合**：显示技能伤害、首领贡献、最大单次伤害、攻击次数、暴击次数、主动/被动伤害比例及推测职业；下方按整场战斗统计玩家 Buff 或怪物 Debuff 的覆盖率，点击状态图标可查看生效时间轴。时间轴会按战斗时长与窗口宽度自动增加主、次刻度。
- **玩家 Buff 管理**：点击左侧“管理 Buff”可启用或删除默认状态；搜索框支持状态名称模糊搜索和 CC ID 精确搜索。玩家 Buff 按类别折叠，点击卡片右上角星标可收藏并固定显示。
- **推测职业**：覆盖元素骑士、圣光颂唱者、黑魔导士、流星射手、圣盾骑士、爆裂骑士枪、枪炮师、禁术炼金师、旋律操纵师和狂怒斗士。
- **攻击技能**：按累计伤害排序显示技能图标、伤害、DPS、占比、最大伤害、使用次数和暴击次数。第一名绿色条为满格，其他技能按相对伤害缩放。
- **人偶伤害**：人偶作为攻击主体时，伤害会自动计入操纵该人偶的玩家；宠物伤害不会计入。
- **团队绘图**：可在“累计输出”和“技能时间轴”之间切换。技能时间轴只显示单个角色，保留该角色本体实际造成伤害的技能，并按技能总伤害从高到低排列，默认显示前 10 个，可点击“显示更多”展开；打开“显示队员”并确认后，可在时间轴左上角切换查看其他队员。已删除过于密集的全队同屏时间轴。横轴为战斗时间，支持缩放和横向滚动；内部背景、边框、按钮、文字和选中态会跟随软件现有的 14 套 UI 颜色同步切换。
- **提醒设置**：集中管理桌面 Buff 图标、持续时间来源、闪烁倒计时、音效倒计时与技能 CD 完成提示。可同时监控多个 Buff 和多个技能。

### 桌面 Buff 提醒（测试功能）

- 在“提醒设置”标签页中按名称或 CC ID 添加一个或多个 Buff，并分别启用桌面图标、闪烁与音效。
- “覆盖层开启”按钮可临时隐藏或恢复 Buff 与技能 CD 两个覆盖层；暂停时不会删除配置，也不会停止后台计时和统计。软件下次启动时会自动恢复显示。
- Buff、Debuff、技能 CD、瞄准、Boss 机制与层数提示共用“锁定覆盖层”选项。锁定时全部保持鼠标穿透，不影响游戏点击；解锁时每个实际提示区域都可直接拖动。
- Buff、Debuff、技能 CD、瞄准、Boss 机制与层数提示恢复为 v1.3.8 的透明 WebView 覆盖窗口，软件底层负责置顶、鼠标穿透和解锁拖动。
- 软件运行后会显示在 Windows 右下角托盘。右键托盘图标可分别勾选“关闭 Buff/技能 覆盖”“关闭 Debuff 覆盖”“静音”，或选择“关闭程序”；这是临时隐藏覆盖层的推荐方式，隐藏和恢复不会重置当前计时与统计。
- “透明度”滑杆可在 20%～100% 之间同时调整 Buff 图标、技能图标、粒子和倒计时的透明度。WebView 层保留 Buff/Debuff 临期脉冲、技能冷却扇形/就绪爆发、瞄准蓄力亮光、Boss 危险闪光与层数提示光效。
- “DPI”默认选择“自动”，会按照悬浮窗当前所在显示器的实际缩放校正窗口。若个别电脑自动识别不正确，可手动选择与 Windows“显示缩放”一致的 100%～300%，保存后立即生效。
- 启用“显示图标”后，该 Buff 会常驻悬浮栏：尚未监测到时为黑白暗色，实际生效后恢复彩色并显示倒计时。
- 桌面提醒只读取私有状态包指出的本机精确目标 ID；即使 CN 服务器没有重发玩家实体资料，不召唤宠物也能识别。队友或宠物把 Buff 加到本机角色上仍会提醒；已确认是宠物的目标、其他玩家和其他玩家的宠物不会触发。
- “提醒设置”页右上角直接提供图标大小、提醒音量及固定的 X、Y 屏幕坐标，不再打开额外设定窗口。坐标输入后会立即移动。
- 图标大小按正方形计算，例如 30 px 即 30×30；倒计时以白字黑边显示在图标正下方。覆盖层在洛奇或 DilmeterCN 位于前台时显示；锁定时穿透鼠标，解锁时显示青色定位边框。
- 可直接输入 X/Y，也可解锁后拖动 Buff、Debuff 或任意技能 CD、瞄准、Boss 机制与层数提示。拖动期间设置页坐标会随动，松手即保存；新增、删除或修改其他提醒规则仍点击该区“保存设定”。
- “自动读取”只使用状态数据中的有效失效时间；若游戏数据未提供时长，会以绿色小字提示“不能识别持续时间”，不会猜测或套用备用值。也可改用“手动固定时长”。重复获得或提前续上同一 Buff 时，会以最新获得时间重新计时。
- 闪烁提前秒数与音效提前秒数相互独立；选择音效或点击“试听”会立即播放一次，以确认系统音量与播放环境正常。
- 每个 Buff 可选择内置音效，也可上传一个不超过 10 MB 的 MP3/WAV 作为自己的自定义提示音；软件会复制保存，原文件之后移动或删除也不影响播放。

### 技能 CD 完成提示（测试功能）

- 在“提醒设置”页的“技能 CD 好了提示”中，可按技能名称或技能 ID 搜索并添加多个技能；为每个技能填写当前装备与状态下的实际 CD 秒数。
- **螺旋爆裂（59145）**与**蓄势突击（59104）**会自动显示“短时 CD、累计 CD、技能 CD”三个独立设置。累计 CD 是一个持续倒数的时间池，每次使用都会把一份完整的短时 CD 加入当前剩余值。例如短时 CD 为 3 秒：第一下立即计为 3 秒；隔 1 秒使用第二下时为 `2+3=5` 秒；再隔 1 秒使用第三下时为 `4+3=7` 秒。停止使用后，累计 CD 自然倒数至 0 并恢复初始状态；累计值达到设定上限后进入完整技能 CD，技能 CD 期间收到的重复技能数据会被忽略，完成时再提示。
- “技能 CD 好了提示”标题右侧的“图标大小”可在 24～96 px 间独立调整技能覆盖层图标，不受 Buff 图标大小影响；修改时即时预览，点击该区域的“保存设定”后保留。
- 软件会捕捉服务器确认的玩家本体技能释放，并从该时刻开始倒计时。技能完成时，会在该技能自己指定的屏幕坐标显示图标：图标逐渐显现、放大，伴随青白色光粒子，随后逐渐消失。
- 主动特技会自动读取其施放后由服务器赋予本机角色的状态信号，不需要用户另行开启 CC 监控；频道切换时收到的过期状态快照不会误启动 CD。
- 勾选“技能图标一直显示”后，技能冷却期间会以灰色图标和倒计时常驻显示；CD 完成时播放提示动画，之后恢复为彩色常驻图标。
- 每个技能提醒都有独立的 X、Y 输入框，坐标以屏幕左上角为 `(0, 0)`，允许把多个技能分别放在不同位置；全部坐标由同一个“保存设定”按钮保存。
- 当前版本读取到的是“服务器确认技能已使用”，协议中尚未找到权威的剩余 CD 或条件刷新事件。因此固定 CD 可以按填写秒数提示，但特殊条件造成的提前刷新、动态减 CD、充能或共享 CD 暂不能保证准确。
- 技能 CD 提示会沿实体归属关系识别人偶、海德拉等由本机角色部署或操纵的技能；普通宠物技能不会触发。若某个无伤害技能的服务器协议没有下发可确认的使用事件，软件不会凭客户端动画猜测 CD。
- **托亚灵震爆**是例外：在技能搜索框输入“托亚灵震爆”或 ID `27012` 添加后，软件会读取服务器发送的托亚灵能量（0%～100%），而不是按固定 CD 猜测。
- 托亚灵提醒比例默认是 95%，用户可自行改为 1%～100%。勾选“能量槽一直显示”时，图标会常驻：彩色技能图像从下向上随能量填充，未充能部分显示为灰色，百分比位于图标正下方并按整数舍去小数显示；不勾选时，达到设定比例后持续显示，充满 100% 时自动隐藏。
- 托亚灵能量第一次达到 100% 时，会把当时仍在冷却且已经捕捉过使用记录的技能更新为就绪；不会让从未使用过的技能凭空触发，也不会同时播放一串技能完成音效。能量降到 100% 以下后再次充满，才会再次触发。
- 登录、换线或本机角色实体发生变化时，托亚灵能量会先回到“等待服务器数据”状态，以服务器下一条能量数据重新建立进度，不沿用上一频道的数值。

### Boss Debuff 提醒（测试功能）

- Debuff 提醒只跟踪一个当前 Boss。默认要求目标最大血量不少于 1 亿；也可在“自定义 Boss 种族”中按 CN 名称或种族 ID 搜索并添加例外目标。若用户当前选中的目标符合条件则优先跟踪，否则选择血量更高、最近进入战斗的一个。
- 普通怪物、小怪和其他未被选中的目标不会触发 Debuff 图标或音效，避免场上有多个目标时反复播报。
- 合格 Boss 出现后，Debuff 覆盖层第一行只显示 Boss 名称，第二行显示尚未补齐或即将失效的 Debuff 图标；全部补齐后，名称与图标会一起隐藏。
- Boss 首次出现时，尚未补齐的 Debuff 只显示图标而不播放音效。音效只用于临近失效，或曾经补上后已经失效但尚未重新补充的 Debuff。
- 多个 Debuff 同时需要提示时只播放一次音效；音效播放期间和紧随其后的合并时间内不会排队逐个播放。
- 可通过右下角托盘单独勾选“关闭 Debuff 覆盖”临时隐藏该栏；恢复显示不会清除 Boss、覆盖率或失效时间记录。

### 安乐碎片机制血条

- 在“提醒设置 → Boss 特殊机制提醒 → 安乐碎片机制”中，分别勾选普通米耶尔 80%、60%、40% 或米耶尔：悔恨 80% 阶段，然后点击“保存设定”。
- 对应机制开始后，选中符合条件的安乐碎片会显示放大血条；切换碎片时跟随目标，目标死亡、消失或改选其他目标时隐藏。
- 四个阶段共用 X/Y 坐标、50%～200% 大小及 20%～100% 透明度，无需重复调整。
- 点击“预览血条”可显示 5 秒预览；解锁覆盖层后可拖动血条调整位置。
- 原有 60% 阶段的开关、大小和位置会迁移到新设置；新增阶段默认关闭，需自行勾选。环绕球和射线提醒仍分别设置。

### 伤害增益效果计时条

1. 打开“提醒设置 → 伤害增益效果计时条”，点击“添加计时条”。
2. 选择“技能”或“Character Condition”作为触发来源，通过名称候选项或 ID 指定技能／状态，并选择作用对象“自身”或“怪物”。
3. 填写持续时间（秒）；勾选“到期后一直显示空条”可常驻保留图标和空条，不勾选则到期隐藏。
4. 选择横向或纵向，并设置大小（50%～200%）、透明度（20%～100%）和 X/Y 坐标。可预览，解锁覆盖层后可拖动调整位置。
5. 点击本区域的“保存设定”。检测到匹配技能执行或状态出现后开始倒数，重复触发会重新计时；匹配状态提前消失时结束该计时。

横向显示图标和名称，纵向保留图标并省略名称。剩余时间显示在进度条中央；条随时间缩短，颜色逐渐从青绿经黄橙转为红色。计时以用户填写的持续时间为准，不自动推算游戏实际增伤数值。
