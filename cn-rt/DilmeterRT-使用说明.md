# DilmeterRT 使用说明

DilmeterRT 是《洛奇》CN 服务器使用的路由模式伤害监测工具，适合 DilmeterCN 无法读取 UU 加速器“路由模式”流量时使用。

当前版本：**v1.4.1**。

## v1.4.1 主要更新

- “Boss 特殊机制提醒”新增“米耶尔 60% 安乐碎片”独立开关；仅在米耶尔进入 60% 阶段后，选中三只对应机制碎片时显示放大血条。
- 识别限定为最大生命值 `63,803,160`、编号 `7604～7606` 的碎片，排除 Boss 背部及 80%/40% 阶段的同名目标。
- 碎片死亡、消失或改选其他目标时自动隐藏；三只碎片全部处理后不会继续占用覆盖层。
- 血条支持自定义 X/Y 坐标、50%～200% 大小、5 秒软件内预览；解锁覆盖层后也可以直接拖动并保存位置。

## 一、需要的软件环境

- 操作系统：Windows 10 或 Windows 11，64 位版本。
- Microsoft Edge WebView2 Runtime：用于显示软件界面。Windows 10/11 通常已经自带；若启动时提示缺少 WebView2，请安装微软官方运行库。
- 建议安装 Npcap：DilmeterRT 会优先尝试 Npcap，无法读取路由模式流量时再自动切换到 WinDivert/WFP。
- 请先完整解压 ZIP。`DilmeterRT-v1.4.1.exe`、`WinDivert.dll` 和 `WinDivert64.sys` 必须放在同一目录，不能只单独复制 EXE，也不要直接在压缩包内运行。
- WinDivert 后端需要管理员权限。软件无法切换到路由模式捕捉时，请关闭软件，再右键 EXE 选择“以管理员身份运行”。

RT 版附带的 WinDivert 是网络驱动组件，部分安全软件可能因此显示风险提示。DilmeterRT 只被动读取符合游戏服务器过滤条件的入站 TCP 数据，不修改或回注网络数据。若安全软件或游戏保护程序持续提示异常，请停止使用 RT，并优先改用 DilmeterCN。

## 二、首次启动与服务器选择

1. 双击 `DilmeterRT-v1.4.1.exe`。软件可以在游戏之前或之后启动。
2. 在软件右上角的“服务器”中选择角色所在服务器：伊鲁夏或亚特。
3. 开启 **加速器兼容**。选择会自动保存，下次打开软件时继续使用上次设置。
4. 启动游戏并登录角色。
5. **软件与游戏都已运行后，需要在游戏内切换一次地图，软件才会开始捕捉。** 可以通过进入另一场景、房间或频道触发新的连接数据。
6. 软件会先尝试 Npcap；无法取得游戏正文时，状态栏会提示正在启用 WinDivert/WFP 路由模式后端。状态变成“正在监测”后即可进入战斗。

如果一直显示“等待游戏”或“正在识别网络连接”，请依次确认：

- 所选服务器与角色实际所在服务器一致。
- UU 加速器已处于路由模式，软件内“加速器兼容”已经开启。
- 已在游戏内切换一次地图。
- EXE、`WinDivert.dll`、`WinDivert64.sys` 位于同一目录。
- 已尝试以管理员身份运行 DilmeterRT。

## 三、软件功能

### 状态与服务器

- 顶部状态会显示“等待游戏”“正在连接游戏”“正在监测”“记录回放”或错误提示。
- “服务器”可在伊鲁夏与亚特之间切换。运行中切换时，当前捕捉会停止并重新等待所选服务器，不需要重启软件。
- 加速器兼容模式只有在成功解析出洛奇封包后才会锁定连接，不会只因为检测到加速器进程就开始统计。
- 本版本目前仅适用于《洛奇》CN 服务器。

### 战斗目标与分享角色

- **战斗目标**：选择要查看的首领或战斗对象；名称后会显示该场战斗的起止时间，方便区分同一目标的先后场次。
- **分享角色**：选择要查看和生成图片的玩家。角色名称后会显示该角色伤害及对当前首领的贡献占比。
- **记录 DPS**：关闭后仍保留 Buff、Debuff、技能 CD 与 Boss 机制提醒，但不再生成新的伤害统计，也不会把新的伤害事件写入自动 NDJSON 日志。

### 顶部功能按钮

- **技能栏**：打开独立技能栏配置。每格最多可录制 8 段、每段最多同时按 4 个键，例如 `Ctrl+[ → Q`。点击输入默认关闭；需要移动时先解除锁定并保存，再拖动悬浮栏。
- **刷新信息**：从软件当前日志重新载入实时战斗数据。查看导入记录后，也可用它返回本次运行的实时数据。
- **导入记录**：导入软件生成的 `.json` 战斗记录，也兼容原始 `.ndjson`、`.txt`，用于重新查看历史数据。
- **导出日志**：把当前选择的首领场次保存为 UTF-8 `.json` 文件，之后可以再次导入。
- **复制图片**：按游戏“详细战斗统计”界面生成分享图并复制到剪贴板，可直接粘贴到聊天软件。若系统不允许直接写入剪贴板，会自动改为保存 PNG。
- **清空数据**：清除当前页面已经统计的数据，不会删除磁盘中已经保存或自动生成的日志文件。

软件自动生成的原始记录保存在 EXE 所在文件夹的 `data\logs`。首次启动新版时会复制旧 `%AppData%\MabinogiDpsDesktop` 中尚未迁移的数据，旧文件不会删除。清空页面数据不会删除这些日志文件。

当 `data\logs` 中的日志总大小超过 10 GB，或存在两个月以前的日志时，软件会询问是否清理。你可以选择截止日期并先查看文件数量与大小；确认后，只有该日期 00:00 之前的历史日志会移入 Windows 回收站，所选日期当天、本次运行正在写入的日志、子目录和其他文件都会保留。清理后请手动清空回收站以释放磁盘空间。

### 报告标签页

- **综合**：显示技能伤害、首领贡献、最大单次伤害、攻击次数、暴击次数、主动/被动伤害比例及推测职业；下方按整场战斗统计玩家 Buff 或怪物 Debuff 的覆盖率，点击状态图标可查看生效时间轴。时间轴会按战斗时长与窗口宽度自动增加主、次刻度。
- **玩家 Buff 管理**：点击左侧“管理 Buff”可启用或删除默认状态；搜索框支持状态名称模糊搜索和 CC ID 精确搜索。玩家 Buff 按类别折叠，点击卡片右上角星标可收藏并固定显示。
- **推测职业**：覆盖元素骑士、圣光颂唱者、黑魔导士、流星射手、圣盾骑士、爆裂骑士枪、枪炮师、禁术炼金师、旋律操纵师和狂怒斗士。
- **攻击技能**：按累计伤害排序显示技能图标、伤害、DPS、占比、最大伤害、使用次数和暴击次数。第一名绿色条为满格，其他技能按相对伤害缩放。
- **人偶伤害**：人偶作为攻击主体时，伤害会自动计入操纵该人偶的玩家；宠物伤害不会计入。
- **提醒设置**：集中管理桌面 Buff 图标、持续时间来源、闪烁倒计时、音效倒计时，以及技能 CD 完成提示。可同时监控多个 Buff 和多个技能。

### 桌面 Buff 提醒

- 在“提醒设置”标签页中按名称或 CC ID 添加一个或多个 Buff，并分别启用桌面图标、闪烁与音效。
- “覆盖层开启”按钮可临时隐藏或恢复 Buff 与技能 CD 两个覆盖层；暂停时不会删除配置，也不会停止后台计时和统计。软件下次启动时会自动恢复显示。
- Buff、Debuff、技能 CD、瞄准、Boss 机制与层数提示共用“锁定覆盖层”选项。锁定时全部保持鼠标穿透；解锁后每个提示可直接拖动，设置页 X/Y 实时随动并在松手时保存。
- 以上提示恢复为 v1.3.8 的透明 WebView 覆盖窗口；软件底层负责置顶、鼠标穿透和解锁拖动，Buff/Debuff 脉冲、技能冷却扇形/就绪爆发、瞄准蓄力光、Boss 危险闪光和层数提示光效均完整保留。
- 软件运行后会显示在 Windows 右下角托盘。右键托盘图标可分别勾选“关闭 Buff/技能 覆盖”“关闭 Debuff 覆盖”“静音”，或选择“关闭程序”；隐藏覆盖层和静音不会重置当前计时与统计。
- “透明度”滑杆可在 20%～100% 之间同时调整 Buff 图标、技能图标、粒子和倒计时的透明度。
- “DPI”默认选择“自动”，会按照悬浮窗当前所在显示器的实际缩放校正窗口。若个别电脑自动识别不正确，可手动选择与 Windows“显示缩放”一致的 100%～300%，保存后立即生效。
- 启用“显示图标”后，该 Buff 会常驻悬浮栏：尚未监测到时为黑白暗色，实际生效后恢复彩色并显示倒计时。
- 桌面提醒只读取私有状态包指出的本机精确目标 ID。队友或宠物把 Buff 加到本机角色上仍会提醒；已确认是宠物的目标、其他玩家和其他玩家的宠物不会触发。
- “提醒设置”页右上角可直接设置 Buff 图标大小、提醒音量及固定的 X、Y 屏幕坐标。坐标输入后会立即移动。
- 图标大小按正方形计算，例如 30 px 即 30×30；倒计时以白字黑边显示在图标正下方。覆盖层在洛奇或 DilmeterRT 位于前台时显示；锁定时穿透鼠标，解锁时显示青色定位边框。
- 可手动输入 X/Y，也可解锁后拖动 Buff、Debuff 或任意技能 CD、瞄准、Boss 机制与层数提示；拖动坐标实时回写并在松手时保存。其他规则修改仍通过“保存设定”统一保存。
- “自动读取”只使用状态数据中的有效失效时间；若游戏数据未提供时长，会以绿色小字提示“不能识别持续时间”，不会猜测或套用备用值。也可改用“手动固定时长”。重复获得或提前续上同一 Buff 时，会以最新获得时间重新计时。
- 闪烁提前秒数与音效提前秒数相互独立；选择音效或点击“试听”会立即播放一次，以确认系统音量与播放环境正常。

### 米耶尔 60% 安乐碎片放大血条（测试功能）

- 雷内恩的米耶尔到达 60% 血量并开始机制后，选中三只机制安乐碎片中的任意一只，会在独立坐标显示一条放大的目标血条；切换三只碎片时立即跟随。
- 血条同时校验米耶尔归属关系、Boss 已到 60% 以及碎片稳定最大生命 `63,803,160`，不会误识别最大生命 `23,479,564` 的背部碎片或 `38,281,896` 的 80%/40% 机制碎片。
- 当前碎片血量归零、目标消失或取消选择时立即隐藏；三只全部击破后该次放大血条机制自然结束。
- “Boss 特殊机制提醒”列表在环绕球与射线之外新增独立的第三项“米耶尔 60% 安乐碎片”，开关默认开启；它只控制放大血条，不影响另外两项提醒，修改后点击“保存设定”生效。
- 第三项可分别设置血条 X/Y 与 50%～200% 大小；点击“预览血条”会按当前未保存数值显示 5 秒。覆盖层解锁时可直接拖动预览血条并回写坐标，原有 Boss Debuff 逻辑不受影响。

### 技能 CD 完成提示

- 在“提醒设置”页的“技能 CD 好了提示”中，可按技能名称或技能 ID 搜索并添加多个技能；为每个技能填写当前装备与状态下的实际 CD 秒数。
- “技能 CD 好了提示”标题右侧的“图标大小”可在 24～96 px 间独立调整技能覆盖层图标，不受 Buff 图标大小影响；修改时即时预览，点击该区域的“保存设定”后保留。
- 软件会捕捉服务器确认的玩家本体技能释放，并从该时刻开始倒计时。技能完成时，会在该技能自己指定的屏幕坐标显示图标：图标逐渐显现、放大，伴随青白色光粒子与提示音，随后逐渐消失。
- 主动特技会自动读取其施放后由服务器赋予本机角色的状态信号，不需要用户另行开启 CC 监控；频道切换时收到的过期状态快照不会误启动 CD。
- 勾选“技能图标一直显示”后，技能冷却期间会以灰色图标和倒计时常驻显示；CD 完成时播放提示动画，之后恢复为彩色常驻图标。
- 每个技能提醒都有独立的 X、Y 输入框，坐标以屏幕左上角为 `(0, 0)`，允许把多个技能分别放在不同位置；全部坐标由同一个“保存设定”按钮保存。
- 软件读取到的是“服务器确认技能已使用”，协议中尚未找到权威的剩余 CD 或条件刷新事件。因此固定 CD 可以按填写秒数提示，但特殊条件造成的提前刷新、动态减 CD、充能或共享 CD 暂不能保证准确。
- 技能 CD 提示会沿实体归属关系识别人偶、海德拉等由本机角色部署或操纵的技能；普通宠物技能不会触发。若某个无伤害技能的服务器协议没有下发可确认的使用事件，软件不会凭客户端动画猜测 CD。

## 四、使用注意事项

- 软件只在游戏运行并建立对应服务器连接时监测新数据；脱离游戏仍可启动软件、导入记录和查看历史结果。
- 每次打开软件、切换服务器或网络线路变化后，请在游戏内切换一次地图。
- 不要删除或重命名 RT 压缩包中的 WinDivert 文件。
- 若出现网络或游戏保护程序异常，请立即关闭 DilmeterRT，并改用 DilmeterCN。
